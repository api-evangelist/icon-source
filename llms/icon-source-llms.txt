# Icon Source

> Icon Source is a Denver, Colorado marketplace connecting brands, marketing agencies and
> universities with professional and college athletes for endorsement, appearance, speaking and
> social-media deals, including Name, Image and Likeness (NIL) engagements. Founded 2018 by Chase
> Garrett. Brands search verified athletes by location, interest, rate, audience size and
> demographics, build and send contracts, and pay athletes in-platform; Icon Source charges a 10%
> transaction fee on each deal signed and closed. Icon Suite (March 2022) adds NIL disclosure and
> compliance tooling for universities.

## Important note for agents

Icon Source publishes NO public API. There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection, SDK, webhook catalog, MCP server or A2A agent card.
The product is delivered only as an end-user web application and iOS/Android apps.

The application's backend at `https://api.prod.iconsource.app` is a private tRPC service used by
Icon Source's own clients. tRPC publishes no OpenAPI document or SDL, the endpoint requires an
authenticated session, and it is not offered for third-party integration. Do not treat it as an
integration surface. A legacy AWS Elastic Beanstalk backend at `https://api.iconsource.com`
answers only `GET /health` with `"Healthy"`.

There is no programmatic path to Icon Source data. Human onboarding through sign-up is the only
supported route.
